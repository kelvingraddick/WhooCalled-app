# Recognition marks

The PNG marks in this directory are bundled only for source and carrier recognition in lookup results. They were rendered from Simple Icons brand artwork and retain the brand color used at retrieval.

The app never fetches favicons or provider logos at runtime. `src/components/VisualIdentity.tsx` maps only known carrier aliases and publisher domains to these marks; every other value uses a Whoo Called illustrated fallback with its text label still visible.

Brand names and marks remain the property of their respective owners. Review this directory when adding a new mark or before distributing in a new jurisdiction.
