# Whoo Called Final Asset Kit

This kit uses the two approved source images without redrawing, tracing, gradients, font substitution, or other visual reinterpretation.

## Assets

- `whoo-called-owl-master.png` is the untouched 1254 × 1254 `Whoo-Called-logo.png` approved on September 5, 2026. The dark outline follows the upper edge of the top gold feathers.
- `whoo-called-owl-transparent.png` is a proportional 374 × 386 export of that owl.
- `whoo-called-owl-transparent-1024.png` is the transparent owl used throughout the app, including the diagonal Home illustration. It preserves the existing visible height and placement while using the approved artwork.
- `whoo-called-wordmark-master.png` is the approved "Whoo Called" wordmark at its original 1221 × 343 pixels.
- `whoo-called-wordmark-dark.png` is the same approved wordmark, named for use on dark surfaces.
- `whoo-called-wordmark-transparent.png` is a direct alpha export of the approved wordmark for the Home header. Its visible mark pixels are unchanged; only the opaque charcoal canvas is removed so the wordmark sits cleanly on the Night surface in the supplied design.
- `whoo-called-app-icon-1024.png` is a centered, opaque 1024 × 1024 app-icon export on the Night background.
- `whoo-called-icon-liquid-source.png` is the fitted source for the existing iOS Icon Composer asset.

## Usage

Use the master files whenever an export needs to be made at another size. Transparent owl exports can sit on either app theme. App icons use the Night background. The gold eye-shaped `oo` is part of the approved wordmark and must not be recolored, separated, or redrawn.

Run `swift scripts/export-owl-assets.swift` from the repository root on macOS to regenerate all 39 owl exports, including iOS launch marks, iOS app icons, the Icon Composer source, and Android launcher icons. This performs proportional raster resampling only. It trims the source's outer canvas, retains the owl's soft edges, and preserves the master unchanged. Wordmarks are independent and are not regenerated by this script.

These are raster source assets. Editable vector artwork is intentionally not included because no approved vector source was supplied and tracing would change the approved design.
